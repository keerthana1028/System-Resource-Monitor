# System Resource Monitor

A Python-based desktop system monitoring application that displays real-time information about CPU, RAM, disk, network, and running processes.

## Features

- Real-time CPU usage monitoring
- RAM usage monitoring
- Disk usage monitoring
- Network upload and download statistics
- Running process count
- System status detection
- Automatic data refresh
- Manual refresh option
- Simple and user-friendly desktop interface

## Technologies Used

- Python
- Tkinter
- Psutil
- Matplotlib
- Git & GitHub
